# SDM660 Mi Pad 4: PM660 / PM660L — кнопки, подсветка, зарядка, выключение

Снято 2026-10-16 из sdm660-mainline (`72bc4bb`): `pm8941-pwrkey.c`,
`qcom-pon.c`, `pinctrl-spmi-gpio.c`, `qcom-wled.c`, `qcom_smbx.c`,
`pmi8998_fg.c`, деревья pm660/pm660l/clover. Факты, не код. [C] — в коде,
[I] — вывод. Адреса — 16-битные адреса SPMI внутри SID. Linux пишет
чтением-изменением-записью, если не сказано иное.

## 1. Питание и громкость вниз — PM660 PON, SID 0, база 0x800

- 0x805 PON_SUBTYPE (0x04 — gen2 [I]); 0x801 PON_REV2.
- **0x810 PON_RT_STS: bit0 — питание, bit1 — громкость вниз (RESIN);
  1 = нажата** [C]. Опрос не требует настройки; биты те же для gen1/gen2.
- 0x870 подтяжки (bit1 KPDPWR, bit0 RESIN), 0x871 антидребезг — по
  желанию. **0x840–0x84B (таймеры S1/S2 долгого нажатия) не трогать** [I].

## 2. Громкость вверх — PM660L GPIO7, SID 2, база 0xc600

- 0xc604 TYPE = 0x10; 0xc605 SUBTYPE (0x10/0x11 — LV/MV ожидается [I]).
- Регистры: 0x10 RT_STS (bit0 уровень), 0x40 MODE_CTL, 0x42 DIG_PULL_CTL
  (0 = 30 мкА вверх), 0x43 DIG_IN_CTL, 0x44 (LV/MV) OUT_SOURCE,
  0x46 EN_CTL (bit7).
- Вход с подтяжкой: 0x42 = 0, 0x43 = 0, 0x40 = 0, затем 0x46 = 0x80.
- **Нажата, когда 0xc610 bit0 == 0** (ACTIVE_LOW) [C].

## 3. Подсветка — PM660L WLED4, SID 3 (ctrl 0xd800, sink 0xd900)

- 0xd846 bit7 — модуль (буст) включён. 0xd946 bits 7:4 — строки (clover:
  0x70, строки 0–2). 0xd947 bits 3:0 — синхронизация.
- Яркость, 12 бит, little-endian: строки 0/1/2 — 0xd957/58, 0xd967/68,
  0xd977/78; минимум у WLED4 — 16, максимум 4095.
- **Установить b**: записать в три пары, затем 0xd947 &= ~0xf, |= 0xf.
- **Выключить**: 0xd846 bit7 = 0 (яркость Linux не обнуляет).
- **Включить**: установить b, затем 0xd846 bit7 = 1; OVP первые 10 мс
  игнорировать.
- OVP/ILIM/FREQ/FSC, если загрузчик уже зажёг панель, не переписывать [I].

## 4. Зарядка и батарея — PM660, SID 0

- Подключено: 0x160b bit4 USE_USBIN и bit0 VALID_INPUT (оба) [C].
- 0x1006 bits 2:0: 0–4 заряжается, 5–6 полна, 7 выключено [C].
  0x1007 — здоровье (bit0 холодно, bit1 горячо, bit4 нет батареи…).
- **Сторож зарядника**: 0x1651 (bit0 включён), 0x1653 (bit7 укус снимает
  зарядку), кормление — 0x1643 = 1. Linux его выключает. Оставленный
  загрузчиком и некормленый — зарядка может встать [I]: прочитать и при
  необходимости кормить.
- Топливомер (без SRAM) [C]:
  - заряд: 0x4009/0x400a (меньший из двух), 0xff → 100 %, 0 → 0 %,
    иначе round((raw−1)·98/253) + 1;
  - напряжение: 0x41a0/0x41a1, мкВ = raw·122070/1000;
  - ток: 0x41a2/0x41a3, знаковый, мкА = raw·488281/1000 (плюс = разряд);
  - температура: ((0x4151 & 7) << 8 | 0x4150) в 0.25 K.

## 5. Выключение

Перед PSCI SYSTEM_OFF/RESET Linux задаёт PMIC действие на снятие PS_HOLD
[C]: enable = 0x85a, если 0x801 == 0, иначе 0x85b; enable bit7 = 0;
ждать ≥ 100 мкс; 0x85a bits 3:0 = 4 (выключить) / 7 (жёсткий сброс);
enable bit7 = 1. **Без этого «выключение» может оказаться сбросом** [I].
Режим перезагрузки в загрузчик/recovery — 0x88f bits 7:1.
