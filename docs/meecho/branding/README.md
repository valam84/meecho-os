# MEECHO brand asset pack

Generated from the supplied MEECHO brief.

Included:
- Primary black mark, inverse white mark, and blue colour derivative (SVG)
- Horizontal and vertical lock-ups (SVG)
- Favicon variants: 16/32/48 PNG + SVG, plus ICO
- Simplified silkscreen mark (SVG)
- Compact and full boot banners (ASCII TXT, LF)
- Copyright notice (ASCII TXT, LF)
- Boot output presentation panel (SVG)

Typography:
- Wordmark: custom geometric vector lettering in the supplied/approved style; no third-party font dependency.
- Tagline/preview text: Inter Medium where available. Inter is licensed under SIL Open Font License 1.1.
- Boot panel preview: DejaVu Sans Mono. DejaVu fonts use a permissive license derived from Bitstream Vera.

Notes:
- Favicon drawings are intentionally different by size.
- All favicon PNGs are rendered without antialiasing.
- ASCII TXT files contain only bytes 0x20-0x7E plus LF.
- Colour derivative uses a single blue: #1466F3.
