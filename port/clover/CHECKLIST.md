# Mi Pad 4: что проверить на планшете

Всё ниже собрано и проверено без планшета: на QEMU и хостовыми стендами
на настоящем дереве `sdm660-xiaomi-clover`. Что из этого работает на
железе — неизвестно, пока не проверено на нём. Шаги идут от безопасного к
рискованному; каждый следующий имеет смысл, только если прошёл предыдущий.
Прошивка и откат — в [FLASH.md](FLASH.md).

Каждый шаг — `fastboot boot` (из памяти, на планшете ничего не пишется;
следующая перезагрузка — снова то, что стоит в `boot`). Перезагрузить
зависший планшет: держать питание ~15 с; в fastboot — громкость вниз +
питание.

Что сфотографировать в любом шаге, если что-то не так: экран целиком с
последними строками. Строки драйверов начинаются с их имени: `sdmmc(…)`,
`pmic(…)`, `touch(…)`, `fb(…)`.

## Шаг 1. Запасной образ: `meecho-clover-safe.img`

Одно ядро, без драйвера eMMC — то, что уже работало у Mac, плюс экранная
клавиатура, кнопки и сенсор.

```
fastboot boot meecho-clover-safe.img
```

Ждать: текст загрузки крупным шрифтом, затем `login:` и клавиатура в
нижней трети экрана.

- [ ] **Клавиатура видна** (5 рядов, US-раскладка).
- [ ] **Касание печатает**: набрать `root` и Enter — должно появиться `# `.
      Shift и Ctrl — одноразовые (действуют на следующую клавишу).
- [ ] **Громкость вверх/вниз** — стрелки вверх/вниз (история команд шелла).
- [ ] **Кнопка питания** — гасит и зажигает подсветку (короткое нажатие).
- [ ] В журнале при загрузке строка `pmic(info)battery N%, V, mA; …`
      (потом — раз в 10 минут и при смене зарядки или десятка процентов).
- [ ] Команда `cat /proc/cpuinfo` — одно ядро.

Если касания не печатают — сфотографировать строки `touch(…)`: там
адрес шины, такты, ID чипа и ошибки I²C.

## Шаг 2. Основной образ: `meecho-clover-boot.img`

Все восемь ядер и драйвер eMMC **только на чтение** (без окна `gptpart`
драйвер отказывает в любой записи: `EROFS`).

```
fastboot boot meecho-clover-boot.img
```

- [ ] Дошло до `login:`. Если нет — где остановилось (фото); тогда дальше
      шаг 1 остаётся рабочим вариантом.
- [ ] `cat /proc/cpuinfo` — сколько ядер (ожидается 8). Строки
      `SMP: CPU N did not come up` при загрузке — сфотографировать.
- [ ] Строки `sdmmc(…)` при загрузке. Ожидается примерно:
      `msm: core …; host ctl …`, `adopt: the card is at RCA …`,
      `eMMC adopted: … sectors (… MiB), 8-bit bus, HS400 …`.
      Если вместо этого `clocks iface off/unknown` или `refusing` —
      сфотографировать: драйвер отказался, ничего не трогая.
- [ ] Чтение eMMC (ничего не пишет):
      ```
      dd if=/dev/c0d0 bs=512 skip=1 count=1 2>/dev/null | dd bs=8 count=1 2>/dev/null; echo
      ```
      ожидается `EFI PART` — заголовок GPT.

## Шаг 3. Корень на eMMC: `meecho-clover-emmc.img` + `meecho-clover-root.img`

**Этот шаг стирает данные Android** (раздел `userdata`). Делать, только
если шаг 2 показал `eMMC adopted` и `EFI PART`.

```
gunzip meecho-clover-root.img.gz          # 1 ГиБ
fastboot flash userdata meecho-clover-root.img
fastboot boot meecho-clover-emmc.img
```

- [ ] При загрузке: `sdmmc(info)gpt: "userdata" is sectors …-… (… MiB);
      nothing outside it is reachable` (окно найдено),
      `/dev/c0d0: clean` или `dirty, checking` (проверка ФС),
      `Root is on c0d0 (userdata), driver sdmmc.`
- [ ] `login:`, вход `root`, в системе полный userland: `ls /usr/bin | wc -l`
      (около 300), есть `vi`, `less`, `mtop`.
- [ ] **Запись переживает перезагрузку**: `echo hello > /root/x; sync`,
      `/sbin/reboot`, снова `fastboot boot meecho-clover-emmc.img`,
      `cat /root/x`.
- [ ] `/sbin/reboot` — перезагружает ли (через PSCI). `/sbin/poweroff` —
      выключает ли (не проверено нигде; если зависнет — держать питание).

## Шаг 4. Постоянная установка

Только когда шаг 2 или 3 работает — по [FLASH.md](FLASH.md):
`fastboot flash boot <образ>`.

## Что заведомо не сделано

- Выключение по `poweroff` может не работать (нужен PS_HOLD PMIC,
  `hw-pmic.md`, §5) — не оставлять планшет включённым без нужды.
- Экран сам не гаснет: только кнопкой питания.
- Зарядом MEECHO не управляет — его ведёт аппаратура PMIC; журнал только
  показывает уровень.
- USB (клавиатура, сеть), Wi-Fi, звук, камеры — нет.
- Гнездо SD драйвер не трогает: что его такт включён, не гарантирует никто.
