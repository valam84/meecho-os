# Авария корневой ФС посреди запроса, на плате.
#
# boot.mba собран с вернутым дефектом libminixfs из 5fadae3d1: flushcache
# (port/test/journal/flushcache.c) роняет корневой MFS на NULL в
# lmfs_journal_commit(), пока VFS ждёт его ответа. Ожидается строка VFS про
# корень, сброс и возврат в Armbian - не тихое зависание.
#
# Консоль только слушает: зонд кладут в /root и запускают по ssh. Набирать
# его сюда нельзя - ввод консоли на 115200 портится, и строка с переменной
# дошла до шелла искажённой (2026-10-03, первая попытка). Слушать надо с
# самой загрузки: порт, открытый заново посреди работы, дал один мусор.
# Запуск: board-cycle.sh -e -s -w sched-rootfs-crash.txt, параллельно -
# доставка и запуск зонда по ssh, как только MEECHO ответит.
120 WAIT switching console to 115200
1 BAUD 115200
# U-Boot после смены скорости ждёт Enter (без него плата стоит в загрузчике).
2 <CR>
1 <CR>
420 WAIT login:
600 WAIT root file system
20 WAIT will now be shut down
0 BAUD 1500000
# На 1500000 знаки теряются: ждать короткую метку.
300 WAIT login:
