# Док USB-C в хабе CB2, как его видит вендорский Linux платы
#
# Снято 2026-10-17 с CB2 под Armbian (6.1.115-btt-rockchip64), док
# воткнут в порт 1 хаба Terminus платы через ~680 с после загрузки:
# lsusb, lsusb -t, lsusb -v устройств дока (4-7), dmesg с его появления.
# Снимать заново: ssh cb2-lan, lsusb -v (root), dmesg | grep usb.
#
# Что из этого следует для MEECHO (PORTING-LOG, «Хаб за хабом»):
# - в доке ДВА хаба WCH 1a86:8095 цепочкой: A на порту 1 Terminus, B на
#   порту 3 хаба A; RTL8152 на порту 3 хаба B - то есть три хаба между
#   корневым портом и Ethernet, маршрут 0x331, уровень 3;
# - хабы single TT, 4 порта, wHubCharacteristics 0x0020: питание и защита
#   от перегрузки общие на все порты (ganged), think time 1;
#   bPwrOn2PwrGood 48 (96 мс - драйвер ждёт не меньше 100);
# - RTL8152: две конфигурации, первая - своя (255/255/0), вторая - CDC
#   Ethernet (2/6/0 + 10/0/0 с парой bulk в альтернативе 1, уведомления
#   на 0x83 по 16 байт).  Linux берёт первую своим r8152-cfgselector;
#   xhci MEECHO по правилу usb_choose_configuration() возьмёт вторую;
# - кардридер 349c:0418 на порту 4 хаба A, bulk-only SCSI, без карты.
