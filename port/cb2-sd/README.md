# CB2: гнездо SD и самостоятельная карта MEECHO

## Эталон контроллера SD (снят 2026-10-12 с работающего Armbian)

- `probe.py` — чтение регистров dw-mshc (`0xfe2b0000`, `0xfe2c0000`) и CRU
  через `/dev/mem`, только чтение, FIFO не трогается;
- `linux-reference.txt` — что оно показало, плюс `ios`, фазы, `clk_summary`,
  CID/CSD/SCR карты и её таблица разделов;
- `live.dtb` — дерево, с которым работает вендорское ядро
  (`/sys/firmware/fdt`); его читают стенды `port/test/sdmmc/`;
- `sdtest.sh`, `ref-before.txt` — проверка второго экземпляра `sdmmc` на
  плате: чтение против дайджестов Linux, запись в хвост карты за p2.

## Самостоятельная карта (`port/mksdimg.sh`)

Образ, который пишется на карту целиком (Etcher, Rufus, `dd`): загрузчик,
FAT с ядром, архивом, деревом и `boot.scr` (`port/cb2-sdcard.cmd`), корень
MFS V4 вторым разделом — `/dev/c1d0p1` на плате. Проверка без платы —
`port/t-sdimg-qemu.sh` (корень с того же образа в QEMU).

Загрузчик свой не собирается (блобы DDR и TF-A `rkbin`): берётся с вендорской
карты BTT/Armbian, которая на этой плате работает. В git его нет — U-Boot под
GPL с двоичными блобами Rockchip, не наше, чтобы распространять. Снять:

```sh
# на плате, под Armbian:
dd if=/dev/mmcblk0 of=/tmp/uboot-area.bin bs=512 skip=64 count=32704
# и рядом - дерево, которое загрузчик отдаёт ядру:
#   /boot/dtb/rockchip/rk3566-bigtreetech-cb2.dtb
```

Оба файла кладутся сюда (`uboot-area.bin`, `rk3566-bigtreetech-cb2.dtb`).
`mksdimg.sh` проверяет, что в начале области `RKNS` (idbloader) и что она
ровно 32704 сектора. Снятые 2026-10-12: md5 `cfffc8b0…` и `145a4a03…`.

Перед публикацией образа (GitHub Releases) — отдельно разобраться с
лицензией блобов в области загрузчика и убрать из корня
`/etc/ssh/authorized_keys` разработчика (`mkroot.sh` кладёт его, если файл
есть).
