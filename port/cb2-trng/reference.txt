Проба TRNG RK3566 на живой плате, из вендорского Linux через /dev/mem
=====================================================================

Дата: 2026-09-08.  Скрипт: port/cb2-trng/probe.py

Зачем понадобилось: узел rng@fe388000 в вендорском дереве стоит
status = "disabled", /sys/class/misc/hw_random/rng_current = none. То есть
работающего эталона на этом железе нет ни у кого, и драйвер пришлось бы
писать вслепую. Проба - способ получить эталон, не выходя из системы,
которую можно перезагрузить.

Узел в дереве (снято с платы):

    rng@fe388000
        compatible  = rockchip,cryptov2-rng
        status      = disabled
        reg         = 0xfe388000, размер 0x2000
        clock-names = clk_trng hclk_trng
        reset-names = reset

Такты: в /sys/kernel/debug/clk/clk_summary у clk_trng_ns и hclk_trng_ns
столбец аппаратного включения стоит Y (у соседних crypto - N). То есть
блок затактирован, хотя драйвера у него нет. Это и позволило пробовать:
обращение к незатактированному блоку APB на Rockchip вешает шину.

Раскладка регистров - у mainline (drivers/char/hw_random/rockchip-rng.c,
compatible rockchip,rk3568-rng; оттуда взяты номера, не код; файл GPL,
дерево BSD - как и для dwmac, берётся справка, а не текст):

    CTL         base + 0x0400   бит 0 START, бит 1 ENABLE, 0x3<<4 длина 256 бит
    SAMPLE_CNT  base + 0x0404
    DOUT        base + 0x0410   32 байта

Запись hiword-masked: старшие 16 бит - маска изменяемых младших, как у CRU.

Что ответила плата

Выводы, на которые опирается драйвер MEECHO
-------------------------------------------

1. Блок отвечает и выдаёт разное. Драйвер имеет смысл.
2. Ни такты, ни сброс трогать не нужно: BL31/загрузчик оставляет блок
   затактированным и не в сбросе. Драйверу достаточно отобразить регистры.
   (Если это когда-нибудь перестанет быть верным, симптом будет громкий:
   DOUT одни нули и START не снимается.)
3. START снимается сам за доли миллисекунды - опроса с предельным сроком
   достаточно, прерывание не нужно.
4. CTL после запуска читается как 0x32 = LEN_256|ENABLE, то есть биты
   длины и включения залипают, а START самоснимается. Это и есть признак
   готовности.

Чего проба НЕ говорит
---------------------

Качество чисел. Четыре несовпавших значения доказывают, что блок живой, и
ровно это. Оценка энтропии по AIS-31 / SP 800-90B сюда не входила и здесь
не заявляется: числа идут в пул как ИСТОЧНИК, а не как готовый поток, и
смешиваются в SHA-256 вместе со временами прихода прерываний.
